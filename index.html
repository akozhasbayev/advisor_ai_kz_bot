Как обновить данные: открой этот файл в текстовом редакторе, найди блок const DATA = [ ... ] и поменяй нужные значения (value, period, published, nextUpdate, yoy.value). Сохрани и опубликуй файл заново — приложение обновится при следующем открытии. Бейдж динамики (зелёный/красный) считается автоматически по знаку yoy.value — для карточек, где сам показатель уже ставка/темп роста, туда пишется разница в п.п.; для остальных — % к аналогичному периоду прошлого года.
